#### 🔹 Categorical Features

* Sex
* Pclass (Passenger Class)
* Embarked
* Title (engineered)
* Family Type (engineered)

#### 🔹 Numerical Features

* Age
* Fare
* SibSp (Siblings/Spouses)

* Survived (Binary classification target)

## 🧪 Key Steps Performed

### **PART A — NumPy Deep Dive & Data Loading**

* NumPy broadcasting and array manipulation
* Manual mean, variance, standard deviation calculations
* Dataset loading and structure inspection
* Initial missing value analysis
* Data type auditing and logical corrections

---

### **PART B — Data Cleaning & Feature Engineering**

* **Missing Value Handling**

  * Median & grouped imputation strategies
* **Outlier Detection**

  * IQR analysis
  * Winsorization (capping) instead of row deletion
* **Feature Engineering**

  * Family Size
  * Is Alone flag
  * Title extraction from names
  * Fare per person
* **Categorical Encoding**

  * Label Encoding
  * One-Hot Encoding
* **Feature Scaling**

  * Standardization for ML readiness

---

### **PART C — Advanced Statistical & Group Analysis**

* Survival analysis using multi-factor groupby
* Advanced aggregation with custom functions
* Pivot table analysis
* Social & maritime factor exploration
* Full correlation analysis across features

### **PART D — Visualization, NumPy Analysis & Reporting**

## 📊 Key Insights

* Passenger class (Pclass) has a **strong impact on survival**
* Females had significantly higher survival rates
* Younger passengers showed higher survival probability
* Fare is positively correlated with survival
* Family size shows non-linear influence on survival
* Engineered features outperform raw features in predictive power
